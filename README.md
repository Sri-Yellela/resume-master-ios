![SwiftUI](https://img.shields.io/badge/SwiftUI-000000?style=flat&logo=apple&logoColor=white)

Native iOS companion to Resume Master. Swipe through job listings, build and edit your resume by section, pick a template, preview and export as PDF.

## UI Interactions
- Rotating card stack with velocity-sensitive swipe gestures
- Soft swipe right: queue for auto-apply
- Hard throw right: immediate apply
- Diagonal swipe: star / save
- Left swipe: skip / dismiss
- Gmail-style swipe actions on resume sections
- iMessage-style action receipt badges

## Getting Started

### Requirements
- Mac with Xcode 15+
- iOS 17+ device or simulator
- Apple Developer account (free for simulator, $99/yr for device + App Store)

### Run on Simulator
1. Clone the repo
2. Open `ResumeMaster/ResumeMaster.xcodeproj` in Xcode
3. Select an iOS 17 simulator
4. Press Command-R

### Archive for App Store
1. Product -> Archive in Xcode
2. Distribute App -> App Store Connect
3. TestFlight -> submit for review
